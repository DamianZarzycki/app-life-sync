## STYLING Theme

### Guidelines for STYLING

- Primary styling: Tailwind CSS utility classes
- Custom enhancements: SCSS for animations and interactions
- Design system: Consistent color palette (indigo/purple primary, gray neutrals, red errors)
- Responsive: Mobile-first with md: and lg: breakpoints
- Accessibility: Focus-visible styles and semantic HTML
- Performance: CSS transitions for smooth interactions
- Consistency: Standardized spacing, typography, and color usage
